# 실행 관리 후속 업데이트

기준 `0135b8a`. BrainNet_V2 안에서 구현·검증·커밋·푸시·로컬 Docker 배포를 한 묶음으로 완료한다.

## 사용자 흐름과 완료 조건

- 내 작업함: 참여 중인 프로젝트의 내 담당/내가 만든/전체 과제, 제목 검색, 기한 초과·오늘·7일·기한 없음 필터, 페이지 처리, 정확한 과제 바로 열기.
- 실행 관리: 과제당 최대 50개 체크리스트, 미완료 항목이 있으면 완료 거절. 상태 변경은 기존 버전·선행 조건 검사와 한 트랜잭션으로 처리한다.
- 반복 과제: 마감일과 1–365일 간격을 지정한다. 완료로 변경할 때 다음 회차를 한 번 생성한다. 다시 열고 완료하거나 요청을 재전송해도 같은 회차를 중복 생성하지 않는다. 기준은 기존 마감일이며 놓친 회차를 자동으로 건너뛰지 않는다.
- 다음 회차: 제목·본문·우선순위·유효한 담당자·노드·체크리스트를 복사하고 체크 상태와 의존성은 초기화한다. 후속 회차가 이미 있다면 이전 회차 수정이 전파되지는 않는다.
- 프로젝트 현황: 전체 상태별 수, 미완료 기한 초과/오늘/7일, 선행 과제로 막힌 수, 담당자별 남은 양, 최대 10개 임박 과제. 화면에 로드한 일부 목록이 아닌 DB 전체를 집계한다.
- 백업: 체크리스트·반복 간격·회차 관계를 v2 선택 필드로 보존한다. 구 요청과 백업의 재시도 해시는 유지한다. 복원 그 자체로 새 회차를 생성하지 않는다.

## 화면

흰 작업 화면·남색 강조·목록과 구분선을 유지한다. 내 작업함은 필터→과제 목록, 프로젝트 현황은 숫자 요약→상태 분포→담당자/임박 목록으로 구성한다. 탭 전환·접기·포커스 복원으로 맥락을 유지하며 장식용 움직임은 추가하지 않는다.
날짜 필터의 기준일은 브라우저 현지 날짜를 서버에 명시해서 전달한다. 시각이 없는 마감일 자체는 날짜로 보존한다.

## 검증

전용 DB에서 권한 회수·삭제 프로젝트 비노출, 반복 동시 완료/재완료, 일괄 롤백, 백업 호환을 먼저 확인한다. 전체 회귀는 한 번, 실패 검사는 해당 범위만 반복한다. 개인 DB는 배포 전 백업하고 전후 자료를 비교한다.
