# BrainNet Workspace V3 — 12주 제품 계획

기준: `73f2a33`, 2026-09-22. 팀 협업·개인 지식 관리·AI 분석을 모두 포함한다.
기간은 제품 범위와 운영 관찰을 위한 계획이며, 코드 작성 속도로 운영 검증 기간을 대체하지 않는다.

## 연결할 사용자 흐름

프로젝트에서 아이디어를 찾는다 → 북마크로 모은다 → AI 제안을 검토한다 → 실행 과제로 채택한다 → 담당자·마감일을 정한다 → 토론하고 완료한다.
기존 그래프와 편집 복구, 권한, 작업 이력은 유지한다. 로컬 Docker가 배포 대상이다.

## 설계 원칙

- 시각 방향: 흰 작업 화면과 얇은 구분선, 남색 강조. 그래프 / 실행 보드 / 지식 / 토론 / AI 검토를 프로젝트 내 탐색으로 제공한다.
- 콘텐츠: 프로젝트명이 첫 번째 정보이며, 각 화면은 목록·편집기·현재 상태를 우선한다. 장식용 카드와 마케팅 문구를 넣지 않는다.
- 상호작용: 명시적 저장, 충돌 설명, 재시도, 키보드 조작을 기본으로 한다. AI는 사용자가 요청하고 검토해 채택한다. 자동 유료 호출은 없다.
- 노드 삭제는 과제와 토론을 삭제하지 않는다. 연결만 해제한다. 개인 북마크는 사용자별로 격리한다.
- 변경은 프로젝트 권한 확인과 같은 트랜잭션에서 처리한다. 과제와 댓글은 버전 충돌을 검사한다.
- 개인 DB에서 테스트 초기화 금지. 새 마이그레이션은 전용 DB에서 검증하고 배포 전 SQL 백업을 보관한다.

## 백업 계약

기존 JSON schema v1은 그래프 전용이다. 과제·토론·AI 기록과 개인 북마크를 포함하지 않는다.
schema v2는 그래프·과제·선행 조건·토론·답글·지식 연결·AI 기록·내 북마크를 새 프로젝트로 복원한다. 계정·멤버십·담당자·멘션 대상·알림·투표·활동 이력·서버 초안·AI 한도·개인 템플릿/저장 검색은 이 프로젝트 파일에 포함하지 않는다. 작성자는 복원한 계정으로 지정한다. 모든 DB 자료를 원래 ID와 권한 그대로 복원하는 수단은 PostgreSQL SQL 백업이다.

## 시간이 필요한 운영 확인

실제 AI 제공자의 품질·청구 금액 검증은 사용자 API 키가 설정된 환경에서 수행한다.
요청 건수/문자 수 제한은 금액 상한이 아니다. 이미 전송한 요청의 취소는 제공자 청구를 되돌리지 않는다.
대기 중인 요청은 재시작 후 실행되며, 실행 중 서버가 죽은 요청은 90초 후 INTERRUPTED로 남기고 자동 재호출하지 않는다.
수주간 사용 피드백과 장시간 부하 관찰은 결과를 미리 만들어 표시할 수 없는 운영 단계다.
